# Build a Custom AI Chatbot That Learns from Websites

Welcome to this project-based course where we build a production-ready AI chatbot from scratch.

The goal of this application is to create a custom chatbot that learns from selected websites, processes their content, and answers user questions based on real data.

Instead of generic responses, this chatbot will use website knowledge that we provide.

---

# 🚀 What We Are Building

This project is a full-stack AI application with modern scalable architecture.

## Frontend

- Next.js
- React

## Backend

- Django
- Django REST Framework

## Real-Time Chat

- Django Channels
- WebSockets

## AI Layer

- OpenAI API

## Data Collection

- Scrapy

## Background Tasks

- Celery
- Redis

## Infrastructure

- Docker
- Docker Compose
- Nginx
- PostgreSQL
